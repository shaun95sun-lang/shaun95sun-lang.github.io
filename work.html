  • 三輪 omni 底盤進行中BoltNut 社團的全向輪底盤，用 SolidWorks API 腳本建模。SOLIDWORKS API · Python · ESP32-S3 · JGA25-370

    BoltNut 機器人社的三輪全向底盤。這版的特別之處是用 Python 透過 SolidWorks API 建模：所有尺寸集中在一個設計檔，零件由腳本產生，改尺寸就能重建（做法）。

    • 3 組 omni 輪模組：輪轂、12 顆滾子、JGA25-370 馬達與馬達座
    • 每個輪子都裝 AS5600 磁編碼器量轉角，支架和磁鐵座是自己設計的
    • 控制：ESP32-S3、TB6612FNG 馬達驅動 ×2、降壓模組，3 串 18650 供電
    • 規則：先在電腦裡找現成模型，找不到才自己建

    新零件已建完，下一步是依排針位置幫上層板開槽，再組總組合件做干涉檢查。

  • 擺線減速機 R&D進行中可列印的 10:1 擺線減速機，從參數產生幾何，已改到 v0.7。同系列還有 swerve 舵輪底盤的 CAD 和 BOM。Python · SOLIDWORKS · PETG · AS5600 · ESP32

    給機器手臂用的擺線減速機，目標是用 Bambu X1C 印 PETG，搭配金屬銷和標準軸承。幾何由 Python 依參數產生，也會產生網頁 3D 檢視器和爆炸圖。

    • v0.4：11 針、10:1、側邊繩捲筒輸出，MG996R 和 JGA25-370 兩種馬達版本；完成 SolidWorks 組合件、干涉檢查和列印檔
    • 配合試片：先印一盤 18 件試片，確認孔補償 +0.2 mm 和軸承配合，再印減速機
    • v0.5：輸出改成通用法蘭，可以直接接手臂；齒輪 1:1 帶動 AS5600 量輸出角度
    • v0.6：感測齒輪改 1:5，角度解析度提高 5 倍
    • v0.7：橡皮筋把感測擺臂拉向輸出齒輪，雙齒面接觸消除齒隙

    另外寫了 ESP32 測試韌體，搭配 AS5600 讀輸出角度。
